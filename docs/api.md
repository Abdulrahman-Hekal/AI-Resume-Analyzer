# REST API Documentation

All REST APIs follow standard HTTP conventions, return JSON responses, and utilize standard status codes (`200 OK`, `201 Created`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `409 Conflict`, `422 Unprocessable Entity`).

Interactive documentation is automatically generated by FastAPI at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

---

## 1. Authentication (`/api/auth`)

### Register User
- **Method**: `POST /api/auth/register`
- **Request Body**:
```json
{
  "email": "candidate@example.com",
  "password": "Password123!",
  "full_name": "Alex Morgan",
  "role": "user"
}
```
- **Response** (`201 Created`):
```json
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "email": "candidate@example.com",
    "full_name": "Alex Morgan",
    "role": "user",
    "is_active": true,
    "created_at": "2026-09-27T12:00:00Z"
  }
}
```

### Login
- **Method**: `POST /api/auth/login`
- **Request Body**:
```json
{
  "email": "candidate@example.com",
  "password": "Password123!"
}
```
- **Response** (`200 OK`): TokenResponse object.

### Current User Profile
- **Method**: `GET /api/auth/me`
- **Headers**: `Authorization: Bearer <access_token>`
- **Response** (`200 OK`): UserResponse object.

## 2. Resume Subsystem (`/api/resumes`)

### Upload Resume
- **Method**: `POST /api/resumes`
- **Headers**: `Authorization: Bearer <access_token>`
- **Content-Type**: `multipart/form-data`
- **Form Data**: `file` (.pdf or .docx binary)
- **Response** (`201 Created`):
```json
{
  "id": 12,
  "user_id": 1,
  "filename": "my_resume.pdf",
  "file_type": "pdf",
  "file_size_bytes": 104520,
  "created_at": "2026-09-27T12:05:00Z",
  "has_analysis": false
}
```

### List My Resumes
- **Method**: `GET /api/resumes`
- **Headers**: `Authorization: Bearer <access_token>`
- **Response** (`200 OK`): `{"resumes": [...], "total": 1}`

### Get Resume Details
- **Method**: `GET /api/resumes/{resume_id}`
- **Headers**: `Authorization: Bearer <access_token>`
- **Response** (`200 OK`): Returns metadata plus full extracted `raw_text`.

### Delete Resume
- **Method**: `DELETE /api/resumes/{resume_id}`
- **Headers**: `Authorization: Bearer <access_token>`
- **Response** (`200 OK`): `{"message": "Resume 12 successfully deleted."}`

## 4. Job Management & Search (`/api/jobs`)

### Search & Filter Jobs
- **Method**: `GET /api/jobs/search`
- **Query Parameters**:
  - `q`: Free-text search across title, company, description, location
  - `skill`: Filter by specific skill
  - `min_exp`: Minimum years of experience
  - `max_exp`: Maximum years of experience
  - `location`: Filter location
  - `employment_type`: Filter type (Full-time, Part-time, Contract, Remote)
  - `skip`: Pagination offset (default: 0)
  - `limit`: Pagination limit (default: 50)
- **Response** (`200 OK`): `{"jobs": [...], "total": 15}`

### Create Job
- **Method**: `POST /api/jobs`
- **Headers**: `Authorization: Bearer <access_token>`
- **Request Body**:
```json
{
  "title": "Backend Systems Engineer",
  "company": "Cloud Corp",
  "description": "Develop scalable APIs...",
  "required_skills": ["Python", "FastAPI", "Docker"],
  "preferred_skills": ["Kubernetes"],
  "experience_years": 3.0,
  "education_level": "Bachelor's",
  "location": "Remote",
  "employment_type": "Full-time",
  "salary_range": "$100,000 - $130,000",
  "contact_email": "hiring@cloudcorp.io"
}
```
- **Response** (`201 Created`): JobResponse.

## 7. RAG Knowledge Base Management (`/api/career/knowledge-docs`)

### List Knowledge Documents
- **Method**: `GET /api/career/knowledge-docs`
- **Response** (`200 OK`):
```json
[
  {
    "id": 1,
    "title": "Resume Writing Best Practices: The Google XYZ Formula",
    "category": "resume_guideline",
    "source": "Industry Hiring Rubric",
    "chunks_count": 1,
    "created_at": "2026-09-27T12:00:00Z"
  }
]
```

### Get Knowledge Document Details
- **Method**: `GET /api/career/knowledge-docs/{doc_id}`
- **Response** (`200 OK`):
```json
{
  "id": 1,
  "title": "Resume Writing Best Practices: The Google XYZ Formula",
  "category": "resume_guideline",
  "source": "Industry Hiring Rubric",
  "content": "High-impact resumes clearly differentiate between responsibilities and achievements...",
  "chunks_count": 1,
  "created_at": "2026-09-27T12:00:00Z"
}
```

### Create Knowledge Document
- **Method**: `POST /api/career/knowledge-docs`
- **Headers**: `Authorization: Bearer <access_token>`
- **Request Body**:
```json
{
  "title": "Advanced Python Async Patterns",
  "category": "skill_description",
  "content": "Python's asyncio library enables concurrent I/O-bound operations using async/await syntax...",
  "source": "Python Engineering Guide"
}
```
- **Valid Categories**: `job_description`, `skill_description`, `career_roadmap`, `learning_resource`, `resume_guideline`
- **Response** (`201 Created`): KnowledgeDocResponse with `chunks_count` indicating how many vector chunks were generated.
- **Note**: The document content is automatically chunked, embedded with dense vectors, and indexed for RAG cosine similarity retrieval.

### Delete Knowledge Document
- **Method**: `DELETE /api/career/knowledge-docs/{doc_id}`
- **Headers**: `Authorization: Bearer <access_token>`
- **Response** (`200 OK`):
```json
{
  "message": "Knowledge document 'Advanced Python Async Patterns' (ID 9) and all its vector chunks successfully deleted."
}
```
